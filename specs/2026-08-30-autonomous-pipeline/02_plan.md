## 단계

### 1. 커밋 게이트 제거 — AGENTS.md 10장 개정

- [x] "커밋·푸시 금지(명시적 요청 시만)"를 **"승인된 스펙 범위 안에서는 자동"**으로 바꾼다:
  - 스펙(`02_plan.md`) 승인 = 그 범위의 커밋·푸시·PR 생성·CI 대응·재수정까지 포함 승인
  - 스펙 없는 작업·스펙 밖 변경은 지금처럼 묻는다
  - 금지 명령(`--amend`·`rebase -i`·`reset --hard`·`push --force`·`add -A`)과 `main` 직접 푸시 금지는 그대로
- [x] PR 루프(10장)의 "커밋(사용자 승인 후)" 문구를 새 규칙에 맞게 고친다

- [x] `skills/commit/SKILL.md` — "사용자가 커밋을 요청할 때" 전제를 "승인된 스펙 파이프라인 안에서는 자동 실행"으로 고친다

### 2. PR 이후 절차 — create-pr 스킬 확장 (property-right 참고)
